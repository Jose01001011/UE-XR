# Extended Reality (XR) and User Experience (UEP) Projects Portfolio

This repository contains two Virtual Reality (VR) projects developed as part of the **Extended Reality (XR) and User Experience (UEP)** module at the **Namibia University of Science and Technology (NUST)**.

The projects explore immersive interaction, virtual environments, animation systems, and user experience design using modern VR development tools and workflows.

---

# Project 1: Ostrich Egg Hunt

## Overview

**Ostrich Egg Heist** is an asymmetric Virtual Reality experience set in an African savanna environment. The project explores communication, stealth mechanics, environmental storytelling, and information asymmetry within a VR setting.

The experience revolves around a thief attempting to steal ostrich eggs while avoiding detection. Different participants possess different information, requiring communication, coordination, and decision-making to successfully complete the objective.

## Core Gameplay Roles

### Thief
- Attempts to steal ostrich eggs.
- Must avoid detection by the ostrich.
- Relies on guidance from other participants.

### Signaller
- Observes the environment.
- Uses gesture-based communication.
- Provides movement instructions to the thief.

### VR Observer
- Interprets signals and environmental information.
- Assists in coordinating successful actions.
- Acts as a bridge between participants.

## Features

- Asymmetric gameplay design
- Gesture-based communication system
- Ostrich AI behaviour system
- Stealth mechanics
- Environmental storytelling
- Immersive savanna environment
- VR interaction using Meta Quest 2

## Technologies Used

- Unity
- C#
- XR Interaction Toolkit
- Blender
- Meta Quest 2

# Project 2: Hikakusi Dance VR Animation Enhancement

## Overview

The **Hikakusi Dance VR Project** focuses on improving an existing Virtual Reality experience representing the traditional San Hikakusi dance.

The project enhances immersion, realism, and cultural authenticity by improving NPC movement using motion capture and animation refinement techniques. Rather than creating a new VR experience, the project refines existing character animations through motion capture, rotoscoping, and iterative testing workflows.

## Objectives

- Improve animation realism
- Enhance NPC movement quality
- Increase user immersion and presence
- Preserve cultural authenticity
- Improve rhythm synchronization and dance representation

## Features

- Motion capture integration
- Animation refinement workflow
- NPC movement enhancement
- Blender-to-Unity animation pipeline
- Cultural heritage representation
- Iterative testing and evaluation
- Improved dance realism and synchronization

## Technologies Used

- Unity
- Blender
- Rokoko Motion Capture
- MediaPipe
- C#
- Meta Quest 2
